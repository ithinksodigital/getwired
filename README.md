# Wired

Menu bar utility for macOS that shows Ethernet status in real time.

**Wired is installed from a ready-made build.** This repository hosts the source for transparency; **download the app** from Releases (below).

## Install (GitHub Releases)

1. Open the repository’s **[Releases](https://github.com/ithinksodigital/getwired/releases)** page on GitHub.
2. Download the latest **`Wired.dmg`**.
3. Open the DMG and drag **`Wired.app`** into **Applications**.

## What Wired shows

- Connection state (connected / disconnected)
- Useful interface details (IP, MAC, name)
- Notifications when Ethernet status changes

## Why is the code on GitHub?

The source is public so anyone can **review** what the distributed app does, **report issues**, or suggest improvements. **Install Wired from [Releases](#install-github-releases)** — that is the supported way to use the app.
